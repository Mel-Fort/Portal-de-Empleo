# Portal de Empleo con Presentaciones en Video 💼 🎥

Este proyecto consiste en una aplicación web que simula un portal de empleo moderno donde **candidatos y empresas pueden presentarse mediante vídeos**. 
La experiencia de usuario está centrada en la accesibilidad, la visualización clara de ofertas y la interacción sencilla.

## Características principales 🚀
- Listado de ofertas de empleo dinámico y atractivo. 🎯
- Barra de búsqueda para filtrar empleos en tiempo real. 🔎
- Detalles de cada oferta con video explicativo de la empresa. 📹
- Formulario para que el candidato postule con su propio video. 📤
- Diseño responsive (adaptado a móviles, tablets y escritorio). 🌐
- Efectos visuales en botones y navegación para mejor UX. 🎨
- 
## Tecnologías utilizadas 🛠
- **HTML5** – Estructura semántica.
- **CSS3** – Diseño responsivo y estilizado.
- **JavaScript (puro)** – Lógica del sitio y renderizado dinámico.
